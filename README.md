# Real-Time Fraud Detection System using Spark, Machine Learning, and Streamlit

This project is a complete end-to-end real-time fraud detection system built using Apache Spark for feature engineering, Scikit-learn for machine learning model training, and Streamlit for real-time prediction through a web interface. The entire system is containerized using Docker.

This project demonstrates a production-style machine learning pipeline used in banking, fintech, and payment systems.

---

## Technology Stack

- Python 3.10  
- Apache Spark (PySpark)  
- Scikit-learn  
- Streamlit  
- Docker and Docker Compose  
- PostgreSQL (optional)  
- Apache Airflow (optional)

---

## System Architecture

Raw Transaction Data  
→ Spark Feature Engineering  
→ Machine Learning Model Training  
→ Model Export (model.pkl)  
→ Real-Time Inference using Streamlit UI  

---

## Key Features

- Distributed data processing using Apache Spark  
- Machine learning model built using Random Forest  
- Exported model for real-time inference  
- Live prediction web interface with Streamlit  
- Fully Dockerized system  
- Production-style pipeline design  
- Ready for resumes, interviews, and job portfolios
